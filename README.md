## Что сделано

В ноутбуке реализованы и сравниваются TF-IDF и BM25 на тестовой части WikiQA. Для обоих методов используется одна токенизация: нижний регистр, выделение буквенно-цифровых токенов и удаление английских стоп-слов. Индексы строятся по всему тестовому набору, а ранжирование выполняется отдельно для кандидатов каждого вопроса.

Для BM25 используются два набора параметров:

| Модель | k1 | b |
|---|---:|---:|
| По умолчанию | 1.5 | 0.75 |
| Вариант 1 | 1.2 | 0.60 |

Основная метрика варианта - NDCG@5. Дополнительно в ноутбуке рассчитывается NDCG@10. DCG/NDCG реализованы вручную и проверяются сравнением со `sklearn.metrics.ndcg_score`. Вопросы без правильных ответов не включаются в среднее значение NDCG.
